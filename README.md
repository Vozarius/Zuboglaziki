# Сайт «Зубоглазики»

Сайт использует небольшой Node.js-сервер для проверки доступности Minecraft-порта и безопасной отправки запросов в Discord. Требуется Node.js 20 или новее.

## Настройка

Скопируйте `.env.example` в `.env` и заполните настройки:

- `SERVER_HOST` и `SERVER_PORT` — адрес Minecraft-сервера;
- `MAP_HOST` и `MAP_PORT` — адрес и порт карты; пустой `MAP_HOST` использует `SERVER_HOST`;
- `MAP_SCHEME` — `http` или `https`;
- `DISCORD_WEBHOOK_URL` — секретный URL Discord webhook.

Для запуска локально выполните `npm start`, затем откройте `http://localhost:3000`. При запуске сервер читает `.env`, но переменные окружения хостинга имеют приоритет.

## Развёртывание и защита конфига

`.env` и остальные локальные `.env.*` добавлены в `.gitignore`; в репозитории хранится только `.env.example` без секретов. Сам веб-сервер раздаёт файлы из разрешённой папки сайта и не раздаёт скрытые файлы, включая `.env`.

Разместите сайт на хостинге с поддержкой Node.js 20+ и задайте переменные из `.env` в настройках окружения хостинга. Один только GitHub Pages не может выполнять проверку игрового порта или скрыто отправлять Discord webhook: на нём эти серверные функции работать не будут. У Node-хостинга должен быть сетевой доступ к `SERVER_HOST:SERVER_PORT` и к Discord API.
